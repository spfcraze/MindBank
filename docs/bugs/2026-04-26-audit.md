## Critical Bugs Found

### Bug 1: Brain_3D isRunning Not Reset (CRITICAL)
- **File:** `web/dashboard/index.html` (Brain_3D section)
- **Issue:** When STOP clicked, `stopRequested = true` but `isRunning` stays `true`
- **Impact:** Cannot restart animation after stopping
- **Fix:** Reset `isRunning = false` in stop handler

### Bug 2: Brain_3D Animation Memory Leak (HIGH)
- **File:** `web/dashboard/index.html`
- **Issue:** `requestAnimationFrame` not cancelled on tab switch
- **Impact:** Browser memory grows, CPU usage increases
- **Fix:** Store animation ID, cancel on tab switch

### Bug 3: Brain_3D Three.js Cleanup (HIGH)
- **File:** `web/dashboard/index.html`
- **Issue:** Geometries, materials, textures not disposed
- **Impact:** GPU memory leak
- **Fix:** Call `.dispose()` on all Three.js objects

### Bug 4: Quick Create Missing "session" Type (MEDIUM)
- **File:** `web/dashboard/index.html`
- **Issue:** Node type dropdown doesn't include "session"
- **Impact:** Cannot create session nodes manually
- **Fix:** Add "session" to dropdown options
